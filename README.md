I built a Resume Analyzer that uses the Gemini API to read and evaluate resumes in PDF format, providing smart scoring and personalized feedback.
✨ What it does:
• Analyzes resumes using AI
• Generates a score based on content quality
• Highlights strengths and identifies weaknesses
• Allows users to select job domains for targeted analysis
• Includes login system and database integration
Goal: Help users understand how well their resume aligns with industry expectations.
This project enhanced my skills in AI integration, backend development, and building user-focused applications.
